# To-Do Task Manager (MERN)

A clean task management dashboard built using MongoDB, Express, React, and Node.js.

## Tech Stack
- Frontend: React (Vite), Axios, CSS
- Backend: Express, Node.js
- Database: MongoDB (Mongoose)
- Auth: JWT, bcryptjs

## Features
- User registration and login with encrypted credentials
- Task CRUD operations (create, view, edit title/deadline, remove)
- Due date tracking with automatic overdue indicators
- Task search and status filtering (All, Active, Completed)
- Dark and light theme toggle with persistent preferences
